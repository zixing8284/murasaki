# Tooltip

`Tooltip` shows a Windows 98 info popup for hover and focus targets.

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `text` | `string` | required | Tooltip text. |
| `delay` | `number` | `400` | Delay before showing in milliseconds. |
| `side` | `'top' \| 'bottom'` | `'top'` | Preferred placement, with viewport flipping. |
| `className` | `string` | - | Popup classes. |
| `children` | `ReactNode` | required | Trigger content. |

## Accessibility

Tooltip adds `aria-describedby` while visible and renders the popup with `role="tooltip"`.
