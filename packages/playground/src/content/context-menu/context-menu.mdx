# ContextMenu

The ContextMenu components provide a Windows 98 styled right-click popup menu using a compound component pattern. The menu appears at the pointer position, clamped to the viewport or a container element.

## Usage

<CodeBlock code={`import {
  ContextMenu,
  ContextMenuContent,
  ContextMenuTrigger,
  Menu,
  MenuItem,
} from 'murasaki-react98'

<ContextMenu>
  <ContextMenuTrigger>
    <div>Right-click me</div>
  </ContextMenuTrigger>
  <ContextMenuContent>
    <Menu>
      <MenuItem>Copy</MenuItem>
      <MenuItem>Paste</MenuItem>
      <MenuItem disabled>Delete</MenuItem>
    </Menu>
  </ContextMenuContent>
</ContextMenu>`} />

## Accessibility

- `ContextMenuContent` renders as a portal with `position: fixed`.
- Menu items should use `role="menuitem"` (via the `Menu`/`MenuItem` components).
- Disabled items set `aria-disabled="true"`.
- The menu closes on Escape and on outside pointerdown.

## Keyboard

| Key | Behavior |
|-----|----------|
| `Escape` | Close the menu |
| `Tab` | Move focus (no focus trap — by design for context menus) |

Note: Arrow-key navigation between menu items is not yet implemented. This will be added when `useRovingFocus` is integrated with the Menu component.

## SSR

ContextMenu is a client component (`'use client'`). The menu content is portal-rendered and only appears after a user interaction (right-click), so there is no server-rendered popup content. The trigger element renders normally on the server.
