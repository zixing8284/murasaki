# Dropdown

The `Dropdown` component renders a Windows 98 styled custom dropdown with a trigger button and a rendered option list.
It supports controlled and uncontrolled modes, keyboard navigation, and an optional label.

A native `DropdownNative` variant is also available, which uses the browser's built-in `<select>` element.

## Usage

<CodeBlock code={`import { Dropdown } from 'murasaki-react98'

<Dropdown
  name="color"
  options={[
    { value: 'red', label: 'Red' },
    { value: 'green', label: 'Green' },
    { value: 'blue', label: 'Blue' },
  ]}
  defaultValue="red"
  width={200}
/>`} />

## DropdownNative

A lighter variant using the browser's native `<select>` element.

<CodeBlock code={`import { DropdownNative } from 'murasaki-react98'

<DropdownNative name="size">
  <option value="small">Small</option>
  <option value="medium">Medium</option>
  <option value="large">Large</option>
</DropdownNative>`} />
