# Menu

The Menu components render a Windows 98 styled vertical menu with items, icons, and separators. They are building blocks for context menus, dropdown menus, and window menus.

## Accessibility

- `Menu` renders `role="menu"` on a `<menu>` element.
- `MenuItem` renders `role="menuitem"` on an `<li>` with `aria-disabled` when disabled.
- `MenuSeparator` renders `role="separator"` on an `<li>`.
- Disabled items have `aria-disabled="true"` and `data-disabled` for CSS styling.
- Selected items have `data-selected` for CSS styling.

## Keyboard

| Key | Behavior |
|-----|----------|
| `ArrowDown` / `ArrowUp` | Navigate between items (when integrated with a parent that provides roving focus) |
| `Enter` / `Space` | Activate the focused item |
| `Escape` | Close the menu (when used inside a dismissable layer) |

Menu is a stateless building block. Arrow-key navigation is provided by the parent component (e.g., ContextMenu, WindowMenuBar) that wraps it.

## SSR

Menu is a client component (`'use client'`). It renders static HTML with ARIA roles — no interactive state is managed internally. Server-rendered markup is identical to client-rendered output. No hydration mismatch risk.
