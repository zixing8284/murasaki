# Tabs

The `Tabs` component provides a Windows 98 styled tabbed interface using a compound component pattern.
It supports both controlled and uncontrolled modes.

## Usage

<CodeBlock code={`import { Tabs } from 'murasaki-react98'

<Tabs defaultValue="tab1">
  <Tabs.List>
    <Tabs.Tab value="tab1">General</Tabs.Tab>
    <Tabs.Tab value="tab2">Advanced</Tabs.Tab>
  </Tabs.List>
  <Tabs.Panel value="tab1">General content</Tabs.Panel>
