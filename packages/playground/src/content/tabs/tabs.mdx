# Tabs

The Tabs components provide a Windows 98 styled tabbed interface using a compound component pattern.
They support both controlled and uncontrolled modes.

## Usage

<CodeBlock code={`import { Tab, TabList, TabPanel, Tabs } from 'murasaki-react98'

<Tabs defaultValue="tab1">
  <TabList>
    <Tab value="tab1">General</Tab>
    <Tab value="tab2">Advanced</Tab>
  </TabList>
  <TabPanel value="tab1">General content</TabPanel>
  <TabPanel value="tab2">Advanced content</TabPanel>
</Tabs>`} />
