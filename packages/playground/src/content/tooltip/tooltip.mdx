# Tooltip

The Tooltip component displays a floating text label on hover or focus, positioned relative to its trigger element with automatic viewport flip.

## Accessibility

- The tooltip popup has no ARIA role by default — it is a visual-only hint.
- The tooltip is triggered by pointer enter/leave and focus/blur on the trigger element.
- The tooltip dismisses on Escape key.
- The tooltip content is portal-rendered and positioned with `position: fixed`.
- For screen-reader-accessible descriptions, use `aria-describedby` on the trigger instead of a Tooltip.

## Keyboard

| Key | Behavior |
|-----|----------|
| `Escape` | Dismiss the tooltip |

The tooltip shows on focus and hides on blur, so keyboard users can trigger it by tabbing to the trigger element.

## SSR

Tooltip is a client component (`'use client'`). The tooltip popup is not rendered on the server — it only appears after user interaction (hover or focus). The trigger element renders normally on the server. No hydration mismatch risk.
