# TreeView

The TreeView components render a hierarchical, collapsible tree structure using native HTML `<details>`/`<summary>` elements with ARIA tree semantics. They support both controlled and uncontrolled expand/collapse, keyboard navigation, and selection highlighting.

## Accessibility

- `TreeView` renders `role="tree"` on its root `<ul>`.
- Branch items render `role="treeitem"` on `<summary>` with `aria-expanded` reflecting the open state.
- Leaf items render `role="treeitem"` on a `<div>`.
- Disabled items set `aria-disabled="true"` and are removed from the tab order.
- Child lists render `role="group"`.
- The tree uses native `<details>`/`<summary>` for expand/collapse, providing built-in accessibility.

## Keyboard

| Key | Behavior |
|-----|----------|
| `ArrowDown` | Move focus to the next visible item |
| `ArrowUp` | Move focus to the previous visible item |
| `ArrowRight` | Expand a collapsed branch, or move to the first child |
| `ArrowLeft` | Collapse an expanded branch, or move to the parent |
| `Home` | Move focus to the first visible item |
| `End` | Move focus to the last visible item |

Items inside collapsed branches are skipped during navigation.

## SSR

TreeView is a client component (`'use client'`). Branch items use native `<details open>` for expand state, which is reflected in server-rendered markup. The `defaultExpanded` or `expanded` props control the initial HTML `open` attribute, ensuring stable server/client output.
