# Button

> A command button, also referred to as a push button, is a control that causes the application to perform some action when the user clicks it.
>
> — _Microsoft Windows User Experience_

## Quick Start

```tsx
import { Button } from "#/components/button/button";

// Basic button
<Button>OK</Button>

// With click handler
<Button onClick={handleClick}>Save</Button>

// Active (pressed) state
<Button active>Pressed</Button>

// Disabled state
<Button disabled>Can't Click</Button>

// Button group
<div className="flex gap-2">
  <Button>OK</Button>
  <Button>Cancel</Button>
</div>
```

## Props

| Prop        | Type         | Required | Default | Description                   |
| ----------- | ------------ | -------- | ------- | ----------------------------- |
| `children`  | `ReactNode`  | No       | -       | Button content                |
| `active`    | `boolean`    | No       | `false` | Show pressed/active state     |
| `disabled`  | `boolean`    | No       | `false` | Disable the button            |
| `className` | `string`     | No       | -       | Additional CSS classes        |
| `onClick`   | `() => void` | No       | -       | Click event handler           |

Also accepts all standard `<button>` attributes.

## Visual States

- **Normal**: Raised 3D shadow effect
- **Active** (prop): Sunken effect for pressed state
- **Active** (pseudo-class): Sunken effect when clicked
- **Focus**: Dotted outline (Win98 style)
- **Disabled**: Embossed text with shadow
