# Checkbox

> A check box represents an independent or non-exclusive choice.
>
> — _Microsoft Windows User Experience_

## Quick Start

```tsx
import { Checkbox } from "#/components/checkbox/checkbox";

// Basic checkbox
<Checkbox name="feature">Enable feature</Checkbox>

// Pre-checked
<Checkbox name="toolbar" defaultChecked>Show toolbar</Checkbox>

// Controlled
const [checked, setChecked] = useState(false);
<Checkbox name="opt" checked={checked} onChange={(e) => setChecked(e.target.checked)}>
  Option ({checked ? "on" : "off"})
</Checkbox>

// Checkbox group
<div className="flex flex-col gap-2">
  <Checkbox name="opt1">Option 1</Checkbox>
  <Checkbox name="opt2" defaultChecked>Option 2</Checkbox>
  <Checkbox name="opt3">Option 3</Checkbox>
</div>
```

## Props

| Prop             | Type                 | Required | Default | Description                    |
| ---------------- | -------------------- | -------- | ------- | ------------------------------ |
| `children`       | `ReactNode`          | No       | -       | Label text                     |
| `name`           | `string`             | No       | -       | Input name attribute           |
| `checked`        | `boolean`            | No       | -       | Controlled checked state       |
| `defaultChecked` | `boolean`            | No       | -       | Initial checked (uncontrolled) |
| `disabled`       | `boolean`            | No       | `false` | Disable the checkbox           |
| `className`      | `string`             | No       | -       | Additional CSS classes         |
| `onChange`       | `ChangeEventHandler` | No       | -       | Change event handler           |

Also accepts all standard **input** element attributes (except **type**).
