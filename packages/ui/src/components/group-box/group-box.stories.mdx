# GroupBox

> A group box is a special control you can use to organize a set of controls. A group box is a rectangular frame with an optional label that surrounds a set of controls.
>
> — _Microsoft Windows User Experience_

A GroupBox contains a sunken outer border and a raised inner border, resembling an engraved box around the controls. It can also contain a label.

## Quick Start

```tsx
import { GroupBox } from "#/components/group-box/group-box";

<GroupBox label="Settings">
  <Checkbox name="option1">Option 1</Checkbox>
  <Checkbox name="option2">Option 2</Checkbox>
</GroupBox>;
```

## Props

| Prop        | Type        | Required | Default | Description                          |
| ----------- | ----------- | -------- | ------- | ------------------------------------ |
| `label`     | `ReactNode` | No       | -       | Label displayed at the top           |
| `children`  | `ReactNode` | No       | -       | Content to be grouped inside the box |
| `className` | `string`    | No       | -       | Additional CSS classes               |

Also accepts all standard `<fieldset>` attributes.
