# OptionButton

> An option button, also referred to as a radio button, represents a single choice within a limited set of mutually exclusive choices. That is, the user can choose only one set of options.
>
> — _Microsoft Windows User Experience_

OptionButtons **must** be used within an `OptionGroup` component. The `OptionGroup` manages the shared state and provides the `name` attribute for all radio inputs in the group.

## Quick Start

```tsx
import { useState } from "react";

import { OptionButton } from "@/components/option-button/option-button";
import { OptionGroup } from "@/components/option-button/option-group";

// Basic usage with OptionGroup
const [selected, setSelected] = useState("option1");

<OptionGroup name="example" selectedValue={selected} onChange={setSelected}>
  <OptionButton value="option1">Option 1</OptionButton>
  <OptionButton value="option2">Option 2</OptionButton>
  <OptionButton value="option3">Option 3</OptionButton>
</OptionGroup>;
```

## Props

### OptionGroup

| Prop            | Type                      | Required | Default | Description                           |
| --------------- | ------------------------- | -------- | ------- | ------------------------------------- |
| `name`          | `string`                  | **Yes**  | -       | Shared name attribute for all radios  |
| `selectedValue` | `string`                  | No       | -       | Currently selected value (controlled) |
| `onChange`      | `(value: string) => void` | No       | -       | Callback when selection changes       |
| `children`      | `ReactNode`               | No       | -       | OptionButton components               |

### OptionButton

| Prop             | Type                 | Required | Default | Description                      |
| ---------------- | -------------------- | -------- | ------- | -------------------------------- |
| `value`          | `string`             | **Yes**  | -       | Value for this option            |
| `children`       | `ReactNode`          | No       | -       | Label text                       |
| `disabled`       | `boolean`            | No       | `false` | Disable the option button        |
| `className`      | `string`             | No       | -       | Additional CSS classes for input |
| `labelClassName` | `string`             | No       | -       | Additional CSS classes for label |
| `onChange`       | `ChangeEventHandler` | No       | -       | Change event handler             |

Also accepts all standard `<input>` attributes (except `type` and `name`).
