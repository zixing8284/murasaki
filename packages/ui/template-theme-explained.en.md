# Windows `.theme` File Explained

A `.theme` file is a Windows Classic / Windows 98 style theme configuration file. It describes system colors, desktop settings, font metrics, non-client area sizing, and related UI values.

The most important sections are:

- `[Control Panel\Colors]`
- `[Control Panel\Desktop]`
- `[Metrics]`

This document mainly focuses on `[Control Panel\Colors]`, because it controls most visible UI states such as buttons, windows, menus, selection, and disabled appearance.

---

## 1. Structure of a `.theme` File

### `[Theme]`
Basic theme metadata, for example:

- `DisplayName`: the display name of the theme

### `[Control Panel\Colors]`
The system color table. Each entry uses this format:

`Name=R G B`

For example:

`ButtonFace=212 208 200`

This means the button face color is `rgb(212, 208, 200)`.

### `[Control Panel\Desktop]`
Desktop settings such as:

- `Wallpaper`: wallpaper path
- `TileWallpaper`: whether the wallpaper is tiled
- `WallpaperStyle`: wallpaper display style
- `Pattern`: desktop pattern
- `ScreenSaveActive`: whether the screen saver is enabled

### `[Metrics]`
Encoded values for UI sizing, fonts, and non-client metrics, such as:

- `IconMetrics`
- `NonclientMetrics`

These values are usually generated by Windows or a theme editor, not edited manually.

### `[VisualStyles]`
Visual style compatibility settings. In classic themes, this usually does not enable an actual visual style and mostly serves as compatibility metadata.

---

## 2. Meaning of Each `[Control Panel\Colors]` Entry

### Button-related colors

| Key | Purpose |
|---|---|
| `ButtonFace` | Default face/background color for buttons, dialogs, and toolbars |
| `ButtonText` | Button text color |
| `ButtonHilight` | Highlight edge color for 3D borders, usually the top-left edge |
| `ButtonLight` | Secondary highlight color, often the inner light edge |
| `ButtonShadow` | Shadow edge color, usually the lower-right edge |
| `ButtonDkShadow` | Darkest shadow color, often the outer dark border |
| `ButtonAlternateFace` | Alternate face color, used in some dithered or special drawing cases |

### Window and content area

| Key | Purpose |
|---|---|
| `Window` | Background color of window content areas, such as text boxes and list boxes |
| `WindowText` | Text color inside window content areas |
| `WindowFrame` | Outermost window frame color |
| `ActiveBorder` | Border color of the active window |
| `InactiveBorder` | Border color of an inactive window |
| `AppWorkspace` | Background color of an MDI application workspace |

### Title bar colors

| Key | Purpose |
|---|---|
| `ActiveTitle` | Main color of the active window title bar |
| `GradientActiveTitle` | Gradient end color of the active window title bar |
| `TitleText` | Text color of the active window title |
| `InactiveTitle` | Main color of the inactive window title bar |
| `GradientInactiveTitle` | Gradient end color of the inactive window title bar |
| `InactiveTitleText` | Text color of the inactive window title |

### Menu colors

| Key | Purpose |
|---|---|
| `Menu` | Menu background color |
| `MenuBar` | Menu bar background color |
| `MenuHilight` | Background color of a highlighted menu item |
| `MenuText` | Menu text color |

### Selection and highlight

| Key | Purpose |
|---|---|
| `Hilight` | Background color for selected content |
| `HilightText` | Text color for selected content |
| `HotTrackingColor` | Hover or hot-tracking color, such as hyperlink hover color |

### Other colors

| Key | Purpose |
|---|---|
| `GrayText` | Disabled text color |
| `Scrollbar` | Scrollbar background color |
| `Background` | Desktop background color |
| `InfoWindow` | Tooltip background color |
| `InfoText` | Tooltip text color |

## 3. Which Keys Affect Common UI States

### 3.1 When a window is inactive

When a window loses focus, these entries are typically used:

- `InactiveTitle`
- `GradientInactiveTitle`
- `InactiveTitleText`
- `InactiveBorder`

Mapping:

- Title bar background: `InactiveTitle`
- Title bar gradient: `GradientInactiveTitle`
- Title text: `InactiveTitleText`
- Window border: `InactiveBorder`

The active window uses:

- `ActiveTitle`
- `GradientActiveTitle`
- `TitleText`
- `ActiveBorder`

### 3.2 When a button is disabled

For disabled buttons, the main visual change is usually the text and embossed effect rather than a completely different background color.

The main keys involved are:

- `GrayText`
- `ButtonFace`
- `ButtonHilight`
- `ButtonShadow`

Typical appearance:

- The button background usually remains `ButtonFace`
- The button text changes to `GrayText`
- In classic rendering, an offset `ButtonHilight` pass may be drawn to create an embossed disabled-text effect
- The border still relies on `ButtonHilight`, `ButtonShadow`, and `ButtonDkShadow`

So a disabled button is usually not a fully separate color palette. Instead:

- The background mostly stays the same
- The text becomes `GrayText`
- The 3D border still uses the standard button edge colors
- Some controls use a highlight offset to create the classic disabled etched look

### 3.3 Button normal / pressed / raised states

#### Normal
Uses:

- Background: `ButtonFace`
- Text: `ButtonText`
- Top-left light edges: `ButtonHilight` / `ButtonLight`
- Bottom-right dark edges: `ButtonShadow` / `ButtonDkShadow`

#### Pressed
When pressed, the 3D border is usually inverted:

- Top-left becomes dark
- Bottom-right becomes light

This makes the button look sunken instead of raised.

The same edge colors are involved:

- `ButtonHilight`
- `ButtonLight`
- `ButtonShadow`
- `ButtonDkShadow`

### 3.4 Selected text or selected list items

Uses:

- Background: `Hilight`
- Text: `HilightText`

Typical scenarios:

- Text selection
- Selected list items
- Selected tree nodes
- Some highlighted menu states

### 3.5 Menu hover / menu highlight

Main keys:

- `MenuHilight`
- `HilightText` or `MenuText`

In classic Windows UI, a highlighted menu item usually appears with:

- Background set to `MenuHilight`
- Text changed to a light or contrasting color, often close to `HilightText`

## 4. Quick Mapping Table

| UI State | Main Keys |
|---|---|
| Active window title bar | `ActiveTitle`, `GradientActiveTitle`, `TitleText`, `ActiveBorder` |
| Inactive window title bar | `InactiveTitle`, `GradientInactiveTitle`, `InactiveTitleText`, `InactiveBorder` |
| Normal button | `ButtonFace`, `ButtonText`, `ButtonHilight`, `ButtonLight`, `ButtonShadow`, `ButtonDkShadow` |
| Disabled button | `GrayText`, `ButtonFace`, `ButtonHilight`, `ButtonShadow` |
| Pressed button | `ButtonHilight`, `ButtonLight`, `ButtonShadow`, `ButtonDkShadow` |
| Selected content | `Hilight`, `HilightText` |
| Highlighted menu item | `MenuHilight`, `MenuText` / `HilightText` |
| Tooltip | `InfoWindow`, `InfoText` |
| Desktop background | `Background` |
