# Windows `.theme` File Explained

A Windows `.theme` file is a Windows Classic / Windows 98 style theme configuration file. It describes system colors, desktop settings, font metrics, non-client area sizing, and related UI values.

For `@murasaki-io/react98`, the most important section is `[Control Panel\Colors]`, because those values map directly to the CSS custom properties used by the component library.

Color values use this format:

```ini
Name=R G B
```

For example:

```ini
ButtonFace=212 208 200
```

This means the button face color is `rgb(212, 208, 200)`.

## File Structure

### `[Theme]`

Basic theme metadata.

| Key | Purpose |
|---|---|
| `DisplayName` | Display name of the theme |

### `[Control Panel\Colors]`

System color table. These values define most visible states: buttons, windows, title bars, menus, selections, disabled text, tooltips, and the desktop background.

### `[Control Panel\Desktop]`

Desktop-level settings.

| Key | Purpose |
|---|---|
| `Wallpaper` | Wallpaper path |
| `TileWallpaper` | Whether the wallpaper is tiled |
| `WallpaperStyle` | Wallpaper display style |
| `Pattern` | Desktop pattern |
| `ScreenSaveActive` | Whether the screen saver is enabled |

### `[Metrics]`

Encoded sizing, font, and non-client area metrics, such as `IconMetrics` and `NonclientMetrics`. These values are usually generated by Windows or a theme editor rather than edited by hand.

### `[VisualStyles]`

Visual style compatibility metadata. Classic themes usually do not enable an actual visual style here.

## `[Control Panel\Colors]` Reference

### Button Colors

| `.theme` key | CSS variable | Purpose |
|---|---|---|
| `ButtonFace` | `--button-face` | Default face/background color for buttons, dialogs, toolbars, and many control surfaces |
| `ButtonText` | `--button-text` | Button text color |
| `ButtonHilight` | `--button-hilight` | Bright 3D border edge, usually the top-left highlight |
| `ButtonLight` | `--button-light` | Secondary bright edge, often the inner light edge |
| `ButtonShadow` | `--button-shadow` | Dark 3D border edge, usually the lower-right shadow |
| `ButtonDkShadow` | `--button-dk-shadow` | Darkest 3D border edge, often the outer dark shadow |
| `ButtonAlternateFace` | `--button-alternate-face` | Alternate face color used by some dithered or special drawing cases |

### Window, Frame, and Content Colors

| `.theme` key | CSS variable | Purpose |
|---|---|---|
| `Window` | `--window` | Background color of content areas such as text boxes and list boxes |
| `WindowText` | `--window-text` | Text color inside window content areas |
| `WindowFrame` | `--window-frame` | Outermost 1px window frame color |
| `ActiveBorder` | `--active-border` | Border color for the active window |
| `InactiveBorder` | `--inactive-border` | Border color for an inactive window |
| `AppWorkspace` | `--app-workspace` | Background color of an MDI application workspace |

### Title Bar Colors

| `.theme` key | CSS variable | Purpose |
|---|---|---|
| `ActiveTitle` | `--active-title` | Main active title bar background color |
| `GradientActiveTitle` | `--gradient-active-title` | Active title bar gradient end color |
| `TitleText` | `--title-text` | Active title bar text color |
| `InactiveTitle` | `--inactive-title` | Main inactive title bar background color |
| `GradientInactiveTitle` | `--gradient-inactive-title` | Inactive title bar gradient end color |
| `InactiveTitleText` | `--inactive-title-text` | Inactive title bar text color |

When a window becomes inactive, the title bar switches from `ActiveTitle` to `InactiveTitle`, the gradient switches from `GradientActiveTitle` to `GradientInactiveTitle`, and the title text switches from `TitleText` to `InactiveTitleText`.

### Selection and Hot Tracking Colors

| `.theme` key | CSS variable | Purpose |
|---|---|---|
| `Hilight` | `--hilight` | Selected item or selected text background color |
| `HilightText` | `--hilight-text` | Selected item or selected text color |
| `HotTrackingColor` | `--hot-tracking-color` | Hot-tracking color, such as hover color for links or icon labels |

### Menu Colors

| `.theme` key | CSS variable | Purpose |
|---|---|---|
| `Menu` | `--menu` | Menu background color |
| `MenuBar` | `--menu-bar` | Menu bar background color. Windows 98 often treats this like `Menu` |
| `MenuHilight` | `--menu-hilight` | Highlighted menu item background color |
| `MenuText` | `--menu-text` | Menu text color |

### Other System Colors

| `.theme` key | CSS variable | Purpose |
|---|---|---|
| `GrayText` | `--gray-text` | Disabled text color used across controls |
| `Scrollbar` | `--scrollbar` | Scrollbar track/background color |
| `Background` | `--background` | Desktop background color |
| `InfoWindow` | `--info-window` | Tooltip background color |
| `InfoText` | `--info-text` | Tooltip text color |

## Common UI State Mapping

### Active Window

| UI part | Main keys |
|---|---|
| Title bar background | `ActiveTitle`, `GradientActiveTitle` |
| Title text | `TitleText` |
| Border | `ActiveBorder` |

### Inactive Window

| UI part | Main keys |
|---|---|
| Title bar background | `InactiveTitle`, `GradientInactiveTitle` |
| Title text | `InactiveTitleText` |
| Border | `InactiveBorder` |

### Normal Button

| UI part | Main keys |
|---|---|
| Background | `ButtonFace` |
| Text | `ButtonText` |
| Top-left raised edges | `ButtonHilight`, `ButtonLight` |
| Bottom-right shadow edges | `ButtonShadow`, `ButtonDkShadow` |

### Disabled Button

Disabled buttons usually do not switch to a separate background palette. The main change is disabled text, often with an embossed classic effect.

| UI part | Main keys |
|---|---|
| Background | `ButtonFace` |
| Text | `GrayText` |
| Embossed highlight offset | `ButtonHilight` |
| 3D border | `ButtonHilight`, `ButtonShadow`, `ButtonDkShadow` |

Classic Windows may draw the disabled label twice: once in `ButtonHilight` with a 1px offset and once in `GrayText`, producing the etched disabled-text look.

### Pressed Button

Pressed buttons invert the 3D edge direction so the control looks sunken instead of raised.

| UI part | Main keys |
|---|---|
| Top-left sunken edges | `ButtonShadow`, `ButtonDkShadow` |
| Bottom-right light edges | `ButtonHilight`, `ButtonLight` |
| Text | `ButtonText`, often visually offset 1px down and right |

### Selection

| UI state | Main keys |
|---|---|
| Selected text | `Hilight`, `HilightText` |
| Selected list item | `Hilight`, `HilightText` |
| Selected tree item | `Hilight`, `HilightText` |

### Menu Highlight

| UI part | Main keys |
|---|---|
| Highlighted menu item background | `MenuHilight` |
| Highlighted menu item text | Usually `HilightText`, sometimes `MenuText` depending on the renderer |

### Tooltip

| UI part | Main keys |
|---|---|
| Background | `InfoWindow` |
| Text | `InfoText` |

## Quick State Table

| UI state | Main keys |
|---|---|
| Active window title bar | `ActiveTitle`, `GradientActiveTitle`, `TitleText`, `ActiveBorder` |
| Inactive window title bar | `InactiveTitle`, `GradientInactiveTitle`, `InactiveTitleText`, `InactiveBorder` |
| Normal button | `ButtonFace`, `ButtonText`, `ButtonHilight`, `ButtonLight`, `ButtonShadow`, `ButtonDkShadow` |
| Disabled button | `GrayText`, `ButtonFace`, `ButtonHilight`, `ButtonShadow`, `ButtonDkShadow` |
| Pressed button | `ButtonHilight`, `ButtonLight`, `ButtonShadow`, `ButtonDkShadow` |
| Selected content | `Hilight`, `HilightText` |
| Highlighted menu item | `MenuHilight`, `MenuText`, `HilightText` |
| Disabled control text | `GrayText` |
| Tooltip | `InfoWindow`, `InfoText` |
| Desktop background | `Background` |

## Interpreting the Default Classic Values

Typical Windows 98 / Windows Classic themes use values like these:

| `.theme` entry | Meaning |
|---|---|
| `ButtonFace=212 208 200` | Classic silver-gray control surface |
| `GrayText=128 128 128` | Disabled text gray |
| `ActiveTitle=10 36 106` | Deep blue active title bar |
| `GradientActiveTitle=166 202 240` | Light blue active title bar gradient end |
| `InactiveTitle=128 128 128` | Gray inactive title bar |
| `GradientInactiveTitle=192 192 192` | Light gray inactive title bar gradient end |
| `InactiveTitleText=212 208 200` | Light gray inactive title text |
| `Hilight=10 36 106` | Deep blue selected item background |
| `HilightText=255 255 255` | White selected item text |

These values are what give the default Windows 98 palette its silver controls, deep blue active selections, gray inactive windows, and pale yellow tooltips.

## Authoring Notes

- Keep values in `R G B` format with channels from `0` to `255`.
- Use `[Control Panel\Colors]` as the source of truth for visual tokens.
- Prefer mapping `.theme` keys to CSS custom properties instead of hardcoding colors in components.
- Disabled controls normally reuse the base control background and change text to `GrayText`.
- Pressed and sunken states usually come from edge inversion, not from a new fill color.
- Inactive windows should update title background, title gradient, title text, and inactive border together.
