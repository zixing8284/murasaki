# NumberBox

> A numeric input component with increment/decrement spinner buttons. It extends TextBox with specialized handling for numeric values, range constraints, and step controls.

## Quick Start

```tsx
import { NumberBox } from "@/components/number-box/number-box";
// Basic number input
<NumberBox placeholder="Enter number..." />
// With label (left position - default)
<NumberBox label="Quantity" placeholder="Type here" />
// With label on top
<NumberBox label="Age" labelPosition="top" />
// With min, max, and step
<NumberBox label="Rating" min={1} max={5} step={0.
5} />
```

## Props

### NumberBox

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `value` | `number` | - | Current numeric value (controlled) |
| `defaultValue` | `number` | `0` | Default numeric value (uncontrolled) |
| `min` | `number` | `Number.MIN_SAFE_INTEGER` | Minimum allowed value |
| `max` | `number` | `Number.MAX_SAFE_INTEGER` | Maximum allowed value |
| `step` | `number` | `1` | Step increment/decrement amount |
| `onChange` | `(value: number) => void` | - | Callback when value changes |
| `label` | `ReactNode` | - | Label text |
| `children` | `ReactNode` | - | Label content (alternative to label prop) |
| `labelPosition` | `"left" \| "top"` | `"left"` | Label position relative to input |
| `disabled` | `boolean` | `false` | Disable the input and buttons |
| `readOnly` | `boolean` | `false` | Make input read-only |
| `className` | `string` | - | Additional class for input element |
| `wrapperClassName` | `string` | - | Additional class for wrapper element |

Plus all standard HTML input attributes except `type`, `value`, `defaultValue`, and `onChange`.

## Behavior

### Value Validation

- Input values are automatically parsed as numbers
- Values are clamped to the `min`/`max` range
- Invalid inputs (empty or non-numeric) reset to valid value on blur

### Spinner Buttons

- Increment button disabled when value equals `max`
- Decrement button disabled when value equals `min`
- Both buttons respect `disabled` and `readOnly` states
- Click handlers use the `step` value for increments

### Keyboard Support

- All native number input keyboard behavior is preserved
- Tab navigation skips spinner buttons (tabIndex={-1})
