# Window

> Every window has a boundary that defines its shape.
>
> — _Microsoft Windows User Experience_

### Title Bar

> At the top edge of the window, inside its border, is the title bar (also referred to as the caption or caption bar), which extends across the width of the window. The title bar identifies the contents of the window.
>
> — _Microsoft Windows User Experience_

## Quick Start

```tsx
import { Window } from "@/components/window/window";

// Basic window
<Window title="My App">Content here</Window>

// Draggable window
<Window title="Drag Me" draggable>...</Window>

// Modal dialog with overlay
<Window
  title="Confirm"
  overlay
  showMinimize={false}
  showMaximize={false}
  onClose={handleClose}
  onOverlayClick={handleClose}
>
  ...
</Window>

// Bounded to container
<Window title="Limited" draggable appendTo={containerElement}>...</Window>
```

## Props

| Prop             | Type          | Required | Default    | Description                                       |
| ---------------- | ------------- | -------- | ---------- | ------------------------------------------------- |
| `title`          | `ReactNode`   | No       | `"Window"` | Title bar text                                    |
| `active`         | `boolean`     | No       | `true`     | Active (blue) or inactive (gray) state            |
| `draggable`      | `boolean`     | No       | `false`    | Enable title bar dragging                         |
| `maximize`       | `boolean`     | No       | `false`    | Start maximized                                   |
| `disableMaximize`| `boolean`     | No       | `false`    | Disable maximize button (grayed icon)             |
| `overlay`        | `boolean`     | No       | `false`    | Show semi-transparent backdrop behind window      |
| `appendTo`       | `HTMLElement` | No       | -          | Position container (enables absolute positioning). If not `document.body`, the container must have `position: relative` CSS. |
| `showHelp`       | `boolean`     | No       | `false`    | Show help (?) button                              |
| `showMinimize`   | `boolean`     | No       | `true`     | Show minimize button                              |
| `showMaximize`   | `boolean`     | No       | `true`     | Show maximize button                              |
| `showClose`      | `boolean`     | No       | `true`     | Show close button                                 |
| `className`      | `string`      | No       | -          | Additional CSS classes                            |
| `onClose`        | `() => void`  | No       | -          | Close button callback                             |
| `onMinimize`     | `() => void`  | No       | -          | Minimize button callback                          |
| `onMaximize`     | `() => void`  | No       | -          | Maximize button callback                          |
| `onOverlayClick` | `() => void`  | No       | -          | Overlay click callback (for click-outside close)  |

## Common Patterns

**Modal Dialog**: Use **overlay** prop with **showMinimize={`false`}** and **showMaximize={`false`}**. Add **onOverlayClick** to allow closing by clicking outside.

**Bounded Window**: By default, the window uses fixed positioning and dragging is bounded to the viewport. Pass **appendTo** to use absolute positioning within that container, with dragging constrained to container bounds. **Note**: The container element must have `position: relative` CSS to ensure proper absolute positioning.

**Maximized Window**: When maximized without **appendTo**, the window becomes fixed and fills the viewport. With **appendTo**, it fills the container instead.

**Overlay Positioning**: The overlay respects **appendTo** - it uses fixed positioning for viewport-level windows and absolute positioning for container-bound windows.
